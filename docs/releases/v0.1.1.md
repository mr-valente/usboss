# USBoss v0.1.1

`USBoss` is a USB controller bridge between Android and Linux.

## Highlights

- Real-hardware-validated XInput forwarding for the 8BitDo Ultimate 2C Wireless Controller over the 2.4G dongle
- Stable `attach-all` behavior with multi-controller support on the Linux client
- Improved reconnect handling around controller power cycles and session recovery
- Cleaner Android TV behavior with the unwanted "Open USBoss to handle ..." prompts removed
- Better verbose logging on both Android and Linux for real-world debugging
- Optional `Boot: On` startup for bringing the Android host back after reboot

## Tested Setup

- NVIDIA Shield / Android TV as host
- Linux as client
- 8BitDo Ultimate 2C Wireless Controller via 2.4G dongle in XInput mode

## Assets

- `usboss-v0.1.1-android-debug.apk`: debug-signed Android APK for sideloading
- `usboss-client-v0.1.1-linux-x86_64.tar.gz`: Linux client binary archive
- `SHA256SUMS.txt`: checksums for the downloadable binaries

## Notes

- The Android APK is debug-signed for sideloading and testing convenience.
- `attach-all` is the recommended Linux runtime mode for everyday use.
- Linux requires `uinput` for XInput devices and `uhid` for HID devices.

## Known Limitations

- Rumble is not implemented yet on the Linux XInput path.
- After an Android reboot, USB permission may still need to be re-approved before controllers become available again.
- With multiple controllers already powered on during an Android reboot, the second controller may require one manual `Grant USB` action before it reconnects.
