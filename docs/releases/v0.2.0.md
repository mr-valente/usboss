# USBoss v0.2.0

`USBoss` is a USB controller bridge between Android and Linux.

## Highlights

- Polished Android host UI redesign for both phone and Android TV / Shield use
- Stable multi-controller `attach-all` forwarding with real hardware validation
- XInput rumble support on the tested Linux XInput path
- Lower-latency forwarding path restored after the `v0.1.1` regression
- Better live state updates for Linux session status and USB permission changes
- Cleaner controller info, logs, and connection details through popup dialogs

## Tested Setup

- NVIDIA Shield / Android TV as host
- Linux as client
- 8BitDo Ultimate 2C Wireless Controller via 2.4G dongle in XInput mode
- Steam controller test input and rumble validation

## Assets

- `usboss-v0.2.0-android-debug.apk`: debug-signed Android APK for sideloading
- `usboss-client-v0.2.0-linux-x86_64.tar.gz`: Linux client binary archive
- `SHA256SUMS.txt`: checksums for the downloadable binaries

## Notes

- The Android APK is debug-signed for sideloading and testing convenience.
- `attach-all` remains the recommended Linux runtime mode for everyday use.
- Linux requires `uinput` for XInput devices and `uhid` for HID devices.
- The Android host UI now keeps the main screen focused on live status and actions, with connection, controller, and log details available through dialogs.

## Known Limitations

- After an Android reboot, USB permission may still need to be re-approved before controllers become available again.
- With multiple controllers already powered on during an Android reboot, the second controller may still require one manual `Grant USB` action before it reconnects.
- The rumble path is currently focused on the tested Xbox 360 style XInput flow.
